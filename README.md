# SecurePresence Web

Site mobil simplu pentru utilizatori.

## Fisiere

- `index.html` - structura paginii
- `styles.css` - design-ul bazat pe Figma
- `app.js` - lista de evenimente si locul unde se va conecta Supabase

## Cum il deschizi

Deschide `index.html` in browser.

## Conectare Supabase mai tarziu

In `app.js`, lista `events` poate fi inlocuita cu date citite din tabela `events`.
